# 🤖 Análise do Mercado Gastronómico de Los Angeles: Estudo de Viabilidade

## 1. Objetivo do Projeto
Realização de uma pesquisa de mercado detalhada sobre o setor de restauração em Los Angeles para fundamentar o plano de negócios de uma nova cafeteria com atendimento automatizado (garçons robôs). O foco é identificar tendências de ocupação, padrões de redes de estabelecimentos e localizações estratégicas para garantir a sustentabilidade do negócio após o impacto inicial da inovação tecnológica.

## 2. Resultados
- **Mapeamento de Tipologias:** Identificação das proporções de estabelecimentos por categoria, destacando o comportamento das redes vs. locais independentes.
- **Dimensionamento de Capacidade:** Determinação do número ideal de assentos com base na média do mercado para cafeterias de sucesso.
- **Inteligência de Localização:** Identificação das 10 ruas com maior densidade comercial e análise de ruas com estabelecimentos únicos para estratégias de diferenciação.
- **Suporte à Decisão:** Elaboração de recomendações estratégicas sobre escalabilidade e posicionamento de marca para apresentação a investidores.

## 3. Ferramentas Utilizadas
- **Linguagem:** Python.
- **Bibliotecas:** Pandas (Processamento), Seaborn e Matplotlib (Visualização de dados avançada).
- **Storytelling:** Google Slides / PowerPoint (convertido para PDF) para apresentação executiva.
- **Ambiente:** VS Code / Jupyter Notebook.

## 4. O que Aprendi (Evidências Técnicas)
- **Visualização com Seaborn:** Aplicação de bibliotecas de alto nível para criar gráficos esteticamente profissionais e fáceis de interpretar por não-especialistas.
- **Engenharia de Atributos (Parsing):** Extração e limpeza de nomes de ruas a partir de colunas de endereços completos utilizando métodos de manipulação de strings.
- **Data Storytelling:** Desenvolvimento da capacidade de traduzir análises estatísticas complexas numa apresentação visual clara e orientada a objetivos de negócio.
- **Análise de Densidade:** Estudo de distribuições de assentos para caracterizar perfis de redes de estabelecimentos.

## 5. Melhorias Futuras
- **Análise de Sentimento:** Integração de dados de avaliações (reviews) para entender a aceitação do público a conceitos inovadores de atendimento.
- **Correlação Socioeconómica:** Cruzamento dos dados de localização com o poder de compra por código postal (ZIP Code).
- **Simulação de Fluxo:** Criação de modelos de ocupação de assentos para prever o ROI (Retorno sobre Investimento) com base na eficiência dos robôs.
